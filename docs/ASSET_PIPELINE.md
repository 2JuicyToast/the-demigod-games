# Asset pipeline

1. Create or edit source assets in `assets/blender/`.
2. Use scripts in `tools/blender/` to prepare or validate assets.
3. Export approved models to `assets/models/`.
4. Import the models into Roblox Studio.
5. Add gameplay behavior through the future Lua structure in `src/`.

Do not treat exported Roblox assets as replacements for the original Blender source files.
